## ▶️ How to Run

1. Install **XAMPP**.
2. Place the project inside the XAMPP `htdocs` directory:

```text
C:\xampp\htdocs\
```

3. Start **Apache** from the XAMPP Control Panel.
4. Open the project in your browser:

```text
http://localhost/wfs/
```

5. Navigate to the required practical folder.

**Examples:**

```text
http://localhost/wfs/cookie/
```

```text
http://localhost/wfs/file/
```

```text
http://localhost/wfs/form/
```

```text
http://localhost/wfs/functions/
```

```text
http://localhost/wfs/session/
```

```text
http://localhost/wfs/car-crud/
```
